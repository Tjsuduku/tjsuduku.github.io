Cloverdale has 1,921 published colours. I built a workflow with Claude Code and Canva that turns the colour database into 4K palette videos by topic.

<div class="case-stats"><div><b>1,921</b><span>colours in the database</span></div><div><b>4K</b><span>video output</span></div><div><b>By topic</b><span>one video per theme</span></div></div>

## How it works

1. The colour database is exported as a CSV
2. Claude Code reads it and picks colours for a topic
3. A Canva template is filled scene by scene
4. The result is exported as a 4K palette video, ready for social

## Why it matters

The team can publish colour content on demand, and every colour shown is a real, published Cloverdale colour.
